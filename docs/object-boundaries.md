## Boundary Table Layout

- `contribution`: Incrementing zero-based ID for each section contribution.
- `module`: Source module number.
- `section`: Output PE section number.
- `offset`: Byte offset relative to output section.
- `size`: Size of contribution in bytes.
- `characteristics`: Original section flags.
- `data_crc`, `reloc_crc`: CRC values recorded in the PDB.
